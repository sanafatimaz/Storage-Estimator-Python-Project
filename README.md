# Storage Estimator

## Project Purpose
This Python program converts storage capacity from gigabytes (GB) to megabytes (MB).

## How to Run
1. Install Python.
2. Open PowerShell in the project folder.
3. Run the command:

```powershell
python storage_estimator.py
```

## Example Input and Output

**Input:**
```text
Enter storage capacity in GB: 5
```

**Output:**
```text
Storage capacity in GB: 5.0
Equivalent storage in MB: 5120.0
```
